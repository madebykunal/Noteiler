# Noteiler

A calm, minimal, distraction-free writing and document editor with an eye-soothing grey-scale theme and seamless export to Markdown, PDF, and plain text.

## Features

- Distraction-free, centered writing workspace
- Smooth custom animated caret
- Real-time word and selection metrics
- Split-pill download button for quick exports (PDF, Markdown, Plain Text, and Copy)
- Offline autosave via localStorage with debounced writes
- Lightweight, memory-safe architecture with dynamic code splitting

## Tech Stack

- React 19
- Vite
- Vanilla CSS
- jsPDF & html2canvas (lazy loaded)

## Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```
